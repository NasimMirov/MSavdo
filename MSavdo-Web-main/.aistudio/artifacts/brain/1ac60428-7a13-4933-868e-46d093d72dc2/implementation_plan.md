# M.Savdo — Интернет-сервис выкупа товаров из Китая

Комплексный веб-сервис для заказа и выкупа товаров с китайских торговых площадок (1688, Pinduoduo) с автоматическим расчетом цен в таджикских сомони (TJS), двухуровневым каталогом, умной авто-категоризацией, строгим соблюдением правил возврата и отправкой готовых заказов в WhatsApp.

## User Review & Critical Decisions

> [!IMPORTANT]
> На основе ответов на уточняющие вопросы согласованы следующие ключевые решения:
> 1. **Формат поставки**: В превью AI Studio разворачивается полноценное интерактивное веб-приложение со встроенным бэкендом и SQLite, а также предоставляются монолитный готовый файл `app.py` (Flask + SQLite) и полные исходные файлы Chrome-расширения (`manifest.json` и `content.js`), готовые для локального запуска в один клик.
> 2. **WhatsApp интеграция**: Ссылка формируется в международном формате Таджикистана `https://wa.me/992444431` (номер 444431 с префиксом страны +992), а в админ-панели доступно поле быстрой настройки номера при необходимости.
> 3. **Демонстрационный каталог**: База данных инициализируется реальными категориями (Электроника, Одежда и обувь, Дом и уют, Аксессуары) и популярными товарами с площадок 1688/Pinduoduo с ценами в CNY, автоматическим пересчетом в TJS (коэффициент 1.6) и галереями фото.

## 1. Overview & Core Concept

- **Что делает сервис**: Позволяет клиентам просматривать каталог отобранных товаров из Китая с ценами в сомони (TJS), искать товары на лету, добавлять их в корзину с обязательным принятием правил сервиса и формировать готовый структурированный заказ в WhatsApp одним кликом.
- **Инструменты для администратора и байера**: 
  - Скрытая панель управления `/admin` с возможностью редактирования цен, названий, категорий, статусов (active/draft) и жестким предупреждением о правиле возврата строго на исходный счет/карту плательщика.
  - POST API эндпоинт `/api/add-product` для автоматического импорта товаров через расширение браузера со смарт-определением категорий, генерацией SKU вида `MS-XXXXXX` и наценкой $TJS = \text{round}(CNY \times 1.6)$.
  - Встроенный в интерфейс просмотрщик и загрузчик готовых файлов `app.py`, `manifest.json` и `content.js`.
- **Целевая аудитория**: Покупатели из Таджикистана, заказывающие трендовые товары, электронику и одежду из Китая с надежной доставкой и прозрачными условиями.

## 2. User Experience & Visual Design

### Ключевые пользовательские сценарии (User Flows):
1. **Витрина и навигация**:
   - Шапка с логотипом M.Savdo, быстрыми ссылками (Каталог, Правила сервиса, Статус заказов), индикатором корзины и кнопкой перехода в панель импорта/админки.
   - Панель живого поиска (`Live Search`) с мгновенной фильтрацией товаров по названию и артикулу без перезагрузки страницы.
   - Двухуровневое меню категорий и подкатегорий (счетчики товаров, фильтрация по категориям).
   - Сетка товаров с чистыми карточками: качественные фото, цена в TJS (и цена поставщика в CNY для прозрачности), артикул SKU, статус наличия.
2. **Карточка товара (Modal / PDP View)**:
   - Галерея фото с миниатюрами и переключением.
   - Название, артикул, категория, цена в TJS с калькулятором выгоды.
   - Кнопка "Добавить в корзину" с тактильным откликом.
3. **Корзина и оформление в WhatsApp**:
   - Локальное сохранение корзины (LocalStorage) с управлением количеством и удалением.
   - Обязательный чекбокс: *"Я ознакомлен и согласен с Правилами сервиса M.Savdo (включая условия возврата средств)"*.
   - Кнопка "Оформить заказ в WhatsApp": генерирует прямую ссылку `https://wa.me/992444431?text=...` с точно отформатированным списком товаров, SKU, количеством и итоговой суммой.
4. **Страница правил (`/rules`)**:
   - Полный регламент "ПРАВИЛА ПОКУПКИ И ИСПОЛЬЗОВАНИЯ СЕРВИСА M.SAVDO Версия 1.1".
   - Акцентный блок на Пункте 6: «Возврат денежных средств осуществляется СТРОГО на ту карту или счет, с которого была произведена исходная оплата».
5. **Админ-панель (`/admin`)**:
   - Красный баннер предупреждения безопасности по возвратам.
   - Таблица товаров с фильтрами по статусу (active/draft) и категории.
   - Модальное окно редактирования/добавления товара.
   - Тестирование API импорта `/api/add-product` прямо из интерфейса (симулятор Chrome-расширения) для проверки автоматической категоризации.
   - Вкладка «Экспорт кода»: просмотр и скачивание готового монолитного `app.py` на Python Flask и файлов Chrome-расширения.

### Визуальный стиль и дизайн-система:
- **Цветовая палитра**: 
  - Основной фон: чистый светлый `#F8FAFC` / `#FFFFFF` с мягкими контрастными поверхностями.
  - Акцентный цвет: премиальный глубокий изумрудно-зеленый (Jade Emerald `#059669` / `#10B981`) и надежный сапфировый индиго (`#1E293B`) — символизируют надежность трансграничной торговли и удобство WhatsApp.
  - Предупреждающий цвет: строгий карминовый бордо (`#DC2626` / `#991B1B`) для правил возврата.
- **Типографика**: 
  - Заголовки: `Plus Jakarta Sans` / `Outfit` с выверенной иерархией.
  - Текст и интерфейс: `Inter` / `Manrope`.
  - Цены и SKU: `font-mono tabular-nums` для строгой финансовой четкости.
- **Анти-слоп дисциплина**: Никаких декоративных фиолетовых градиентов, бессмысленных пульсирующих точек или пилюльных скоплений. Метаданные оформлены чистым текстом с разделителями `·`.

## 3. Key Product Decisions & Trade-Offs

- **Архитектура двойной готовности**:
  - Приложение в AI Studio работает на быстром Express API + SQLite/JSON Store + React интерфейсе, обеспечивая полноценную работу витрины, корзины, живого поиска и API.
  - Параллельно создается автономный, чистый, самодостаточный скрипт `app.py` на Python (Flask + SQLite3) без внешних громоздких зависимостей, с Jinja2 шаблонами, встроенным REST API и SQLite базой данных.
  - Пользователь получает и работающее онлайн-приложение прямо в браузере, и готовый файл Python под ключ.
- **Умная категоризация (Smart Auto-Categorization)**:
  - Алгоритм анализирует `title` товара: сопоставляет с существующими категориями и подкатегориями по морфологическим корням и синонимам.
  - Если точного совпадения нет — создается новая категория на основе ключевого слова/тега товара.
- **Безопасность возвратов**:
  - Предупреждение выводится на всех этапах: в корзине перед отправкой в WhatsApp, в правилах `/rules`, в шапке админ-панели и в модальном окне редактирования товара.

## 4. Technical Architecture & Data Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│                        M.SAVDO PLATFORM ARCHITECTURE                   │
└────────────────────────────────────────────────────────────────────────┘

    [Chrome Extension (1688 / Pinduoduo)]
               │
               │ POST /api/add-product (title, price_cny, images, original_link)
               ▼
    ┌────────────────────────────────────────────────────────────────────┐
    │                        BACKEND API SERVER                          │
    │  - Price Converter: price_tjs = round(price_cny * 1.6)             │
    │  - SKU Generator: MS-XXXXXX                                        │
    │  - Smart Categorizer: Keyword matching & Auto-creation             │
    │  - Strict Refund Validator & Enforcement Notification              │
    └────────────────────────────────────────────────────────────────────┘
               │                                       ▲
               │ Read / Write                          │ REST Calls
               ▼                                       │
    ┌───────────────────────────┐         ┌──────────────────────────────┐
    │     SQLite DATABASE       │         │        CLIENT FRONTEND       │
    │ ├─ categories             │         │ ├─ Storefront (Catalog/Grid) │
    │ │  (id, name, parent_id)  │         │ ├─ Live Fast Search (LIKE)   │
    │ └─ products               │         │ ├─ Product Detail Modal      │
    │    (id, title, desc,      │         │ ├─ Cart (LocalStorage + WA)  │
    │     price_cny, price_tjs, │         │ ├─ Rules (/rules, Clause 6)  │
    │     images, original_link,│         │ └─ Admin Dashboard (/admin)  │
    │     category_id, sku, ...)│         │ └─ Code Exporter (app.py)    │
    └───────────────────────────┘         └──────────────────────────────┘
                                                           │
                                                           │ wa.me/992444431
                                                           ▼
                                               [WhatsApp Messenger]
```

### Схема Базы Данных (SQLite):
1. **Таблица `categories`**:
   - `id`: INTEGER PRIMARY KEY AUTOINCREMENT
   - `name`: TEXT NOT NULL UNIQUE
   - `parent_id`: INTEGER (REFERENCES categories(id), NULL для корневых)
2. **Таблица `products`**:
   - `id`: INTEGER PRIMARY KEY AUTOINCREMENT
   - `title`: TEXT NOT NULL
   - `description`: TEXT
   - `price_cny`: REAL NOT NULL
   - `price_tjs`: INTEGER NOT NULL (рассчитан по формуле round(price_cny * 1.6))
   - `images`: TEXT (URL фото через запятую)
   - `original_link`: TEXT (ссылка 1688/Pinduoduo)
   - `category_id`: INTEGER (REFERENCES categories(id))
   - `sku`: TEXT UNIQUE NOT NULL (формат MS-XXXXXX)
   - `status`: TEXT DEFAULT 'active' ('active' / 'draft')
   - `created_at`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP

## 5. Chrome Extension (Manifest V3) Architecture

- `manifest.json`: Версия 3, разрешения на `activeTab` и `scripting`, хосты `*://*.1688.com/*` и `*://*.pinduoduo.com/*`.
- `content.js`: Добавляет плавающую плашку-кнопку «Импорт в M.Savdo» в карточку товара на 1688 и Pinduoduo, автоматически извлекает название товара, цену в юанях, галерею картинок высокого качества и отправляет POST-запрос на `http://127.0.0.1:5000/api/add-product` с отображением статуса успеха и сгенерированного SKU.
